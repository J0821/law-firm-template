# 律所官网模板（静态演示）

一套六模块静态落地页，面向律师事务所 / 独立执业律师的官网首屏与信息展示。纯前端，无后端、无表单提交、无外部依赖，双击 `index.html` 即可打开。

本仓库与同系列的餐饮模板共用同一套结构思路：**一套代码，换行业文案与配色**。接单时按下面的替换清单改文案与图片即可交付，不需要重新开发。

## 文件结构

```
index.html    六个区块 + 演示提示条 + toast
styles.css    全站样式：变量、组件、三档响应式
app.js        交互：头部滚动态、移动端菜单、入场动画、FAQ 手风琴、办公状态、复制地址
assets/
  hero-room.jpg     首屏底图（会议室）  1600×900
  desk-docs.jpg     地址卡配图（合同桌面）1200×900
  office-hall.jpg   引言区底图（走廊）   1200×900
```

## 六个区块

| 区块 | 锚点 | 内容 |
|---|---|---|
| 首屏 | `#home` | eyebrow、主标题、两句说明、办公状态、两个按钮、向下提示 |
| 业务领域 | `#practice` | 六张卡片（编号 + 名称 + 说明 + 常见场景） |
| 引言 | — | 深色底图 + 一句主张 + 署名 |
| 服务流程 | `#process` | 四步（初次沟通 / 书面方案与费用 / 签约与办理 / 结案与归档） |
| 律师团队 | `#team` | 三张成员卡（圆形姓氏头像 + 姓名 + 头衔与执业年限 + 专长 + 标签） |
| 联系方式 | `#contact` | 工作时间卡（含实时状态）+ 地址卡（配图 + 电话 / 邮箱 / 来访提示 + 复制地址） |
| 常见问题 | `#faq` | 四条手风琴，同时只展开一条 |
| 页脚 | — | 品牌、导航、联系方式、版权、ICP 备案号 |

## 换一家律所要改什么

按顺序逐项替换，改完即是一套新的交付物。

1. `index.html` `<title>`：改成客户名 + 城市，例如「XX 律师事务所 · 诉讼与法律顾问」。
2. 品牌：`你的律所` → 客户所名；`YOUR LAW FIRM` → 英文名或 `LAW OFFICE`；品牌方框里的 `律` → 客户姓氏或所名首字。
3. 全站电话：`000-0000 0000` 与 `tel:00000000000` 两处都要改。
4. 地址：`XX 市 XX 区 XX 路 XX 号 XX 大厦 XX 层`，出现在地址卡、复制按钮的 `data-address`、页脚三处。
5. 邮箱：`【你的邮箱】`。
6. 律师团队：`【律师姓名】`、`【姓】`、`执业 XX 年`、每人一段专长说明与三个标签。
7. 业务领域六卡：按客户实际业务替换名称、说明、常见场景；不需要六个就删卡，网格会自动补位。
8. 服务流程四步：按客户的收费与办案习惯改写。
9. 引言署名：`创始人 · 你的名字`。
10. 页脚 `ICP 备案号：【待填】`：客户域名备案下来后填入。
11. 三张图：换成客户实拍或授权图，替换 `assets/` 同名文件即可，不必改代码；建议长边 1600 左右、单张压到 200KB 以内。
12. 首屏按钮文案：`电话咨询`、`看看能接什么案子`。
13. 顶部演示提示条文案：交付前改成客户名，或直接用 `app.js` 里的关闭按钮逻辑删掉整条。

## 常用参数怎么调

### 办公状态

`app.js` 顶部：

```js
var OFFICE_OPEN = 9 * 60;    // 9:00
var OFFICE_CLOSE = 18 * 60;  // 18:00
```

时间按分钟计。周末固定显示「休息日 · 可预约面谈」。四个状态的文案在 `getOfficeStatus()` 里，直接改文字即可。每 30 秒刷新一次，首屏与联系方式卡共用同一份状态。

### 配色

`styles.css` 顶部 `:root`：

| 变量 | 值 | 用途 |
|---|---|---|
| `--cream` | `#f6f2e9` | 页面浅底 |
| `--cream-2` | `#eee7d9` | 次级浅底 |
| `--paper` | `#fffdf8` | 卡片底 |
| `--ink` | `#1c2620` | 主文字、深色区块底 |
| `--ink-soft` | `#5d6359` | 次要文字 |
| `--copper` | `#8a6438` | 强调色（序号、状态点、链接） |
| `--copper-dark` | `#6d4d29` | 强调色深版 |
| `--line` | `rgba(28,38,32,.12)` | 分隔线 |

改 `--copper` 一处就能换掉全站强调色（改为法院蓝、酒红都成立）。

### 演示提示条

`index.html` 里 `id="demoBar"` 的整条；关闭按钮会把它移除并重算 `--demo-h`。`--demo-h` 同时驱动头部 `top`、首屏上内边距、锚点跳转偏移和首屏高度（`calc(100vh - var(--demo-h))`），所以关掉提示条后所有位置自动复位。

## 验证过的行为

- 615×674（窄屏）：单列布局，汉堡菜单展开/收起、锚点跳转、FAQ 展开收起、复制地址提示、办公状态四态均正常。
- 1440 宽：业务领域三列（每列 385px）、引言区上下留白 112px、页面总高 5365px，无横向溢出。
- 关闭演示提示条后头部与首屏位置自动补偿，无错位。
- 无 JS 时 `<noscript>` 兜底，入场动画元素直接可见，不会出现空白。

## 已知限制

- 无表单后端：`tel:` 与 `mailto:` 之外没有任何数据提交入口。要做询盘表单需另接服务。
- 办公状态只认工作日与整点区间，不识别法定节假日，也不区分「值班律师」。
- 菜单式的强调色（`--copper`）在少数卡片里是写死值，改主色后需要顺带检查 `.field-index`、`.status-dot` 两处。
- 团队卡用的是姓氏方框占位，没有真人照片位；要放照片需在 `.member` 里加一个 `img` 并调整圆形容器。

## 上线前提

- 域名完成 ICP 备案，且截图前把页脚 ICP 号填上；未备案域名不能用作网站访问入口。
- 若做公安联网备案，备案通过后把备案号一并挂到页脚。
- 静态托管最低成本方案：对象存储 + 自定义域名（需备案）。Vercel / Cloudflare Worker 的默认域名在国内不可用。
